# Changelog

All notable changes to the Campanella Pizza Website project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.5] - 2025-10-31

### Changed
- Final polish and bug fixes
- Replaced payment icons with custom SVG versions
- Removed debug styles from CSS
- Standardised CSS logical properties for consistency
- Completed final validation and testing

## [2.4] - 2025-10-30

### Added
- SEO enhancements (meta tags, canonical links, keyword injection)
- Lazy loading for images to improve page load performance
- 404 error page for better user experience
- Standardised responsive breakpoints to 768px
- Comprehensive accessibility features (skip links, ARIA labels, keyboard navigation)

### Enhanced
- Social media integration

## [2.3] - 2025-10-30

### Added
- Comprehensive contact form validation (email, phone, required fields)
- AJAX-style form submission with confirmation modal
- Smooth scroll animations throughout the site

### Enhanced
- Social media integration

## [2.2] - 2025-10-30

### Added
- Accessible menu tabs with keyboard navigation (Arrow keys)
- Debounced search functionality with ARIA live regions
- Gallery lightbox upgrades with keyboard navigation (arrows, ESC) and swipe support
- Category accordions for collapsible menu sections

### Enhanced
- User interaction patterns

## [2.1] - 2025-10-30

### Added
- Shopping cart functionality with local storage persistence
- Dynamic menu loading from JSON data file
- Pizza size selection modal with dynamic pricing
- Quantity selectors and price calculators for menu items
- Cart badge with real-time item count display

### Changed
- Menu rendering from static HTML to dynamic JSON-driven content

## [2.0] - 2025-10-02

### Changed
- Updated changelog naming in README
- General copy polish and improvements

## [1.9] - 2025-10-02

### Added
- Responsiveness Testing and Iteration Across Devices section to README
- Device screenshots (iPhone, iPad mini, iPad Pro, MacBook Pro, iMac) under `images/responsiveness/`
- Screenshots grouped by Mobile, Tablet, Desktop categories
- Standardised `.jpg` extensions

### Changed
- Ignored `.DS_Store` files in git

## [1.8] - 2025-09-29

### Fixed
- Corrected image file naming (removed duplicate extension from `owners.jpg.jpg`)

### Changed

- Updated README content

## [1.7] - 2025-09-26

## [1.6] - 2025-09-20

- Performance optimisations

## [1.5] - 2025-09-12
